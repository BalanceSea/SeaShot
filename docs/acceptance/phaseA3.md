## 交付内容（对照 `docs/plan-inplace-editor.md` 第 3 节 Phase A 的第 4 条）

在 A1/A2 已经稳住的就地标注阶段上，把**标注本身**接上 `AnnotationDocument`：

- **9 种工具都能画**：矩形 / 椭圆 / 箭头 / 画笔 / 高亮 / 文字 / 序号 / 模糊 / 马赛克（+ 选择）
- **坐标系统一**：标注存的是**选区图像坐标**（原点 = 选区左上角），与即将导出的那张图
  同一个像素空间 —— 所以预览**就是** `renderAnnotations()` 的输出（`m_composedSelection`），
  导出时对抓到的选区图再调一次同一个函数，不存在第二套画法
- **交互**（语义对齐 Phase 2 的 `AnnotationCanvas`，但**自绘、不用子控件**）：
  - 形状工具：拖一下成图；画笔/高亮按轨迹采样成折线；序号单击即放置（编号自增）
  - 文字：点击落点 → **自绘输入**（直接吃键盘，画光标，回车提交 / Esc 丢弃），
    不用 `QLineEdit` 子控件（layer-shell 上子控件的输入区在本项目反复咬人）
  - 选择工具：点选（描边/内部按各自语义命中）、拖整体移动、拖角点改尺寸、双击文字改字
  - `Ctrl+Z` / `Ctrl+Shift+Z`（也支持 `Ctrl+Y`）撤销重做；`Delete` 删除选中
  - `Esc` 语义：有文字草稿先丢草稿 → 有草稿/拖动先取消 → 有选中先取消选中 → 都没有才退出
- **「完成」真的把标注带进结果**：`finishCapture()` 里对抓到的选区图跑一次
  `renderAnnotations()`，之后**剪贴板/保存/结果浮层/编辑器全部用合成后的图**
  （这条踩过坑，见下）
- 标注颜色/粗细暂时固定为编辑器的默认值（`#ff4040` / 4px）——颜色与粗细选择器还没做

## 开发中踩到并修掉的一个真问题（值得记）

第一版把标注只合成进了 `m_lastImage`，而 `finishCapture()` 下游的
**剪贴板/保存/结果浮层/编辑器仍在用 `image.image`（未标注的原图）** ——
表现就是"屏幕上画了，回车之后结果里却没有标注"。
验收的第 10 条（区域对照）第一次跑就是 FAIL（RMSE ≈ 0.0025 = 只有桌面漂移），
抓出了这个"画了但没交付"的问题；修法是把下游统一改用合成后的 `result`，
并在代码里留了注释（`Application.cpp::finishCapture`）。
