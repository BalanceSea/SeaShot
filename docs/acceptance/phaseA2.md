## 交付内容（对照 `docs/plan-inplace-editor.md` 第 3 节 Phase A 的第 3 条）

在 A1 已经稳住的 Annotating 阶段上补一条**自绘**紧凑图标工具条（不用子控件，理由见
`docs/plan-inplace-editor.md` 第 2.2 节：layer-shell 上子控件的输入区/合成在本项目反复咬人）：

- **10 个工具按钮**，顺序对齐 QQ/PixPin：选择 / 矩形 / 椭圆 / 箭头 / 画笔 / 高亮 / 文字 / 序号 / 马赛克 / 模糊
  （前 9 个对应数字键 `1`–`9`；**「模糊」没有数字键**，点击可达 —— 见下方"与计划的偏差"）
- **图标来源**：容器、背景、hover/按下/当前态、悬停气泡全部自绘；**图形本身走 `ui/Theme`
  的语义图标表**（`iconToolSelect/…/iconToolMosaic`，与 Phase 2 编辑器工具栏同一套），
  再统一染成单色（当前工具用强调色 `#3daeff`）。实测本机 `主题图标=10/10`；
  主题里取不到时**回退到自绘图形**（`drawToolIcon()`），不会出现空白按钮。
  这样做的好处：就地编辑与编辑器里同一个工具的图标不会长得不一样。
- 右侧贴**选区尺寸**（`540 × 380`），宽度按 `8888 × 8888` 定死，避免 Phase B 拖手柄时整条工具条抖动
- 尾部两个动作按钮：**完成（✓）**、**取消（✕）** —— 点「完成」等价于 `Enter`，点「取消」等价于 `Esc`
- 交互：hover 高亮 + 悬停气泡（显示工具名与数字键，如「矩形  2」）、按下态、当前工具**高亮**（图标转为强调色 + 底色）
- 位置：**优先贴选区下方**，下方放不下自动跑到**上方**；水平方向夹在表面内
- 命中策略（Phase 0 已验证的判定顺序）：**工具条优先**于标注逻辑；落在工具条矩形内但不在按钮上
  也算"点在工具条上"，**不开始标注**
- 几何只有一处真源：`toolOrder()/buildBarCells()/toolbarSize()/toolbarRect()` →
  `toolButtons()/actionButtons()/cellIndexAt()`，绘制、命中、验收共享同一串 cell
- 鼠标追踪：`setMouseTracking(true)`（否则不按键时收不到 `mouseMove`，hover 高亮与气泡都不会出现
  —— 这是 A2 实现时实测踩到的一个点）

## 与计划的偏差（需要你知情）

1. **「模糊」没有数字键**：计划第 2.4 节定的 `1`–`9` 是
   选择/矩形/椭圆/箭头/画笔/高亮/文字/序号/**马赛克**，里面没有「模糊」。
   但编辑器（Phase 2）里模糊与马赛克是两个工具，就地编辑不该少一个 ——
   所以把「模糊」排在最后、只走点击。若你希望 `0` 或者 `Shift+9` 之类也给它一个键，
   Phase B 的快捷键表里一起定。
2. **工具条的「完成/取消」提前做了**：计划把"保存/复制/取消接现有链路"放在 A4。
   这里先接「完成（= Enter）」与「取消（= Esc）」，因为这两个信号 A1 就有了、
   而且顺手解决了"A1 必须按回车才出结果"的别扭。**复制/保存**仍然留到 A4
   （它们需要"先截图再保存/复制"的链路，与浮层那一套要一起理）。
3. 撤销/重做按钮**没做**：等 A3 把标注接到 `AnnotationDocument` 之后再加，
   否则现在就是一对死按钮。

## 已知问题（本轮发现，非 A2 引入）

**`scripts/acceptance-phase4.sh` 的 F 段判据已过期**：

- 现象：`转发=1 停止=1 RECORD_ok=1 path=''`，F 段判 FAIL。
- 根因：录制**成功**了（`RECORD ok frames=31 dropped=0 failed=0 elapsedMs=2034`），
  但常驻实例的录制现在走 `setDeferExport(true)`
  （`Application::beginRecording()`：`m_options.saveTo.isEmpty()` 时延迟导出并弹格式选择浮层
  —— 这是上一轮"录制格式可选 + 导出 GIF/MP4 按钮"故意做的行为），
  所以 `RECORD ok path=` 是空的，而 F 段还在要求它非空并且文件存在。
- 结论：**上一轮的行为变更没有同步更新 F 段判据**，不是 A1/A2 的回归。
- 处理建议（不由我擅自改判据语义）：F 段改成「转发=1 + 停止=1 + `RECORD ok` 出现 +
  中间文件/浮层如预期」，或者给常驻实例加一个 `--save` 语义的转发。
