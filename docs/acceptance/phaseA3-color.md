## 为什么做这一步

A3 之后就地编辑已经能画 9 种工具了，但**颜色与粗细固定**（编辑器的默认值 `#ff4040` / 4px），
工具条右侧还空着。对照 QQ/PixPin，"画出来是什么颜色、多粗"是仅次于"就地编辑"的可见差距，
所以插在 A4（复制/保存按钮）之前先补上。

## 交付内容

工具条上新增两格（仍在同一条自绘工具条里，**没有引入任何子控件**）：

| 格 | 交互 |
| --- | --- |
| **颜色**（显示当前色的圆角色块） | 点一下弹出**色板面板**（2 行 × 5 色：红/橙/黄/绿/青/蓝/紫/粉/白/黑），点色块即生效并收起面板；当前色带强调色描边 |
| **粗细**（显示当前粗细的预览线） | 点一下弹出**滑杆面板**（1–24 px，实时数值 `粗细 N px`），按住滑杆拖动即时生效；面板外点一下/Esc/切工具都会收起 |

面板的点击语义（都实测过）：

- **面板不压选区**：面板放在"远离选区、且不压工具条"的那一侧（与悬停气泡同一套避让规则），
  放不下才换边 —— 标注区不会被自己的 UI 挡住
- 面板**内空白处**点击被吞掉，不当作"开始标注"
- 面板**外**点一下 = 只关面板，这次点击**不画东西**（避免误画）
- `Esc` = 先关面板（仍留在标注阶段），再按才走"丢草稿 / 取消选中 / 退出"
- 切工具/打开另一个面板会自动收起当前面板；面板打开时不画悬停气泡（会挤在同一位置）
- 颜色/粗细对**之后新画**的标注生效（与编辑器一致，不回溯改已画的）

## 还没做 / 可能的下一步

- **颜色/粗细不持久化**：目前只在一次标注会话内有效，重启回到默认 `#ff4040` / 4px。
  若要"记住上次用的"，需要写进 `Settings`（`annotation/color`、`annotation/width`）——
  一句话的事，等你确认要不要。
- 色板是 10 个预设色，**没有取色器/自定义颜色**；也没有"透明/半透明"档。
- 撤销/重做**不含**颜色粗细这类"工具设置"的变化（只记标注本身，与编辑器一致）。
