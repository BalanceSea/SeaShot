## 交付内容（对照用户诉求 ④「选完可继续调整选区，标注不丢」与 ⑤「快捷键对齐」）

### 1. 选区可调整（A2 时画出来的那 8 个手柄终于能拖了）

| 操作 | 行为 |
| --- | --- |
| 拖 **8 个手柄** | 改对应的角/边，其余边不动 |
| 拖 **4 条边**（边框 ±6px 内） | 只改那一条边 |
| 在选区**内部**拖（选择工具，且没点到标注） | 移动整个选区 |
| 在选区内部拖**点到标注** | 移动那条标注（不是选区） |
| 任何**画图工具**下拖手柄/边 | 仍然改选区（手柄优先于"开始画"） |
| 越界 | 夹在虚拟桌面内，**最小 16×16**（拖到翻转也不会变成 0/负数） |
| 鼠标形状 | 对角/水平/垂直/移动 光标随位置变化（`updateCursorFor`） |

**关键语义决定（这条是 Phase B 的核心）**：标注锚定的是**屏幕内容**，不是选区边框。
所以选区一变，标注坐标要**反向平移**（`delta = 旧原点 - 新原点`），
效果就是"框放大了，标注还压在同一块画面上"。
`AnnotationDocument::translateAll()` 会把**当前标注 + 撤销/重做栈里的每一个快照**一起平移 ——
快照不平移的话，之后一撤销标注就会跳到另一个坐标系里（这类 bug 很隐蔽，所以专门做了方法）。

### 2. 快捷键（对齐计划第 2.4 节）

| 键 | 动作 | 状态 |
| --- | --- | --- |
| `1`–`9` | 选择/矩形/椭圆/箭头/画笔/高亮/文字/序号/马赛克 | A2 已有 |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 撤销 / 重做 | A3 已有 |
| `Delete` | 删除选中标注 | A3 已有 |
| `Enter` / 双击 / ✓ | 完成（按设置复制/保存/弹浮层） | A1/A2 已有 |
| **方向键** | 微调选区位置 1px（**Shift = 10px**），尺寸不变 | **B 新增** |
| **`Ctrl+A`** | 全选（整屏 = 虚拟桌面） | **B 新增** |
| **`Ctrl+C`** | 完成并**复制**到剪贴板（**不弹浮层**，与 QQ 的"复制即走"一致） | **B 新增** |
| **`Ctrl+S`** | 完成并**保存**到默认目录（仍弹浮层，带保存路径） | **B 新增** |
| `Esc` | 逐级取消：关面板 → 中断选区拖动 → 丢文字草稿 → 取消草稿/拖动 → 取消选中 → 退出 | B 补全 |

`Ctrl+C` / `Ctrl+S` 的实现：`annotationConfirmed` 信号带上了 `Overlay::ConfirmAction{Plain,Copy,Save}`，
`Application::finishCapture()` 按它决定"强制复制 / 强制保存 / 按设置"，并且 `Copy` 不弹浮层。

## 与计划的偏差 / 已知取舍

- **手柄命中半径 6px**：所以选区边框内侧 6px 的带状区域不能用来"起笔"画标注
  （任何工具下都会被判成改选区）。QQ/PixPin 也是这个取舍，但如果你觉得手感不对，
  可以把容差调到 4px。
- **选区调整不进撤销栈**：`Ctrl+Z` 只管标注的增删改；改选区本身不可撤销
  （但标注坐标与撤销栈是一起平移的，所以不会错位）。
- **`Ctrl+C` 不弹浮层**：与 QQ 一致。若你更想要"复制完还是让我看一眼"，一行就能改。
- **复制仍会重新抓一次屏**（不是直接用冻结帧）——所以 `Ctrl+C` 拿到的图
  与预览可能有"桌面内容漂移"的细微差别。若要**严格所见即所得**，
  可以改成"直接用冻结帧 + 标注"作为结果源（省一次抓屏、也没有漂移）。
  这属于行为选择，等你定。
- **A4（工具条上的复制/保存按钮）**：管道的 `ConfirmAction` 已经通了，
  A4 只剩在 `buildBarCells()` 里加两格 + 在 `activateCell()` 里发对应的 action。
- 颜色/粗细仍**不持久化**。
