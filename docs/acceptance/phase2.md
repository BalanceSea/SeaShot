## 实现说明（与 PLAN 的一句话偏差，需你知情）

- 编辑器用 **QWidget + QPainter** 实现（画布 `AnnotationCanvas` 自绘，工具栏 `QToolBar`），
  而不是 PLAN 里那句「编辑器与配置界面再上 Quick/QML」。理由：标注的命中测试、手柄拖拽、
  行内文字输入都是「2D 绘制 + 坐标映射」，用 QPainter 一套坐标就能写完，且核心（模型/撤销/渲染）
  能作为纯 C++ 被单测覆盖。**如果你希望编辑器界面用 QML，我可以在 Phase 3 之前改**。
- 撤销栈用「整份标注快照」：标注只有几十个，实现简单、行为可预测，避免部分回滚类 bug。
- 文字是单行（行内 `QLineEdit`）；多行文字框目前没做。
- 画布按窗口自适应缩放（不放大超过 100%），没有缩放/平移/滚动条 —— 截图很大时是"缩略显示"。
- 编辑器窗口自身也在 KWin 的「排除出截图」名单里（appId 含 `seashot`），不会被自己截到。
