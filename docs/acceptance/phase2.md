## 实现说明（与 PLAN 的一句话偏差，需你知情）

- 编辑器用 **QWidget + QPainter** 实现（画布 `AnnotationCanvas` 自绘，工具栏 `QToolBar`），
  而不是 PLAN 里那句「编辑器与配置界面再上 Quick/QML」。理由：标注的命中测试、手柄拖拽、
  行内文字输入都是「2D 绘制 + 坐标映射」，用 QPainter 一套坐标就能写完，且核心（模型/撤销/渲染）
  能作为纯 C++ 被单测覆盖。**如果你希望编辑器界面用 QML，我可以在 Phase 3 之前改**。
- 撤销栈用「整份标注快照」：标注只有几十个，实现简单、行为可预测，避免部分回滚类 bug。
- 文字是单行（行内 `QLineEdit`）；多行文字框目前没做。
- 画布按窗口自适应缩放（不放大超过 100%），没有缩放/平移/滚动条 —— 截图很大时是"缩略显示"。
- 编辑器窗口自身也在 KWin 的「排除出截图」名单里（appId 含 `seashot`），不会被自己截到。

### 这轮改动里撞到并修掉的两个坑（都写进了 PLAN 风险表）

1. **结果浮层在普通 `Qt::Tool` 窗口下被全屏应用盖住**（KWin 窗口列表里有它、屏幕上却看不见）。
   现在浮层也用 layer-shell（`LayerOverlay`）+ 「锦 top\|left + 边距」精确定位。
2. **被 kill/崩溃后 KWin 助手脚本残留**：残留脚本里的自排除状态会继续把之后所有
   SeaShot 窗口标成「排除出截图」——表现为浮层/覆盖层再也截不到（排查了很久）。
   现在：① 启动时扫描缓存目录清理死进程的脚本；② SIGTERM/SIGINT 优雅退出并卸载脚本。
   顺带发现：Qt 默认吞掉 `qInfo`，所以 `SS_INFO/SS_WARN` 现在显式写 stderr（否则这类
   “看不见的失败”几乎无法定位）。

### 浮层按钮标签的 bug

`Button` 枚举首位是 `None=0`，标签函数却从 0 开始映射 → 四个按钮全错位
（实测截图里出现两个「关闭」）。已修，现为 编辑（主按钮）/ 另存为 / 复制 / 关闭。
