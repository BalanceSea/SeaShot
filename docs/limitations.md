# 🧭 兼容性与已知限制

本文记录当前实现的适用范围；本机运行日志、截图与授权记录不作为发布文档收录。

## 🖥️ 桌面与截图后端

- **KDE Plasma 6 / KWin Wayland**：通过 KWin ScreenShot2 截图，KWin 助手脚本提供窗口列表与自排除。请使用安装脚本写入 desktop 授权声明。
- **X11**：通过 XCB / MIT-SHM 截图。已有键盘映射测试与 XWayland 冒烟验证，完整 X11 桌面仍需真机验证。
- **XWayland**：X11 后端只能枚举和抓取 X11 客户端窗口，不能替代 Wayland 后端抓取原生 Wayland 窗口。
- **窗口遮挡**：X11 的屏幕区域截图可能包含遮挡物。Wayland 的交互式标注交付冻结屏幕中的选区内容；命令行直接窗口截图走 CaptureWindow。
- **菜单与本应用窗口**：交互式截图先抓取画面，再显示选择层；选区、标注和导出共用这张冻结图。Wayland 区域截图保留调用者的普通窗口，只排除 SeaShot 的截图辅助层。设置、编辑器与菜单可以被截图。

## 🔍 缩放与多显示器

- 合成回归测试覆盖 100%、125%、200% 缩放下的冻结选区、物理尺寸与标注导出。
- 工具栏图标另有 100%、125%、150%、200%、250%、300% 缩放回归测试，验证图标尺寸、居中、着色与按钮边界。
- 区域截图通过模拟 KWin D-Bus 服务验证逻辑坐标、负坐标、原生分辨率及保留本应用窗口的请求选项。
- 真实多显示器、混合缩放、屏幕排列和跨屏拖选仍需真机验证。
- 覆盖层使用整个虚拟桌面并集，不能把单屏合成测试等同于完整多屏支持。

## 🎬 录制与导出

- PipeWire 需要编译时启用 libpipewire，并具有可恢复的 portal ScreenCast 授权 token；不可用时回退到截图轮询。
- 轮询采帧的实时表现取决于分辨率、截图后端与机器负载；丢帧会复用上一帧补足时长，不能恢复缺失的运动细节。
- H.264 / yuv420p 导出时，奇数宽高向右或向下补齐 1 像素。
- 无损中间文件会占用较多磁盘，录制器定期检查临时目录可用空间，低于 2 GiB 时停止采集。
- 交互式录制只保留当前录制的待导出结果，建议在开始下一次录制或退出前完成导出。

## 🔤 OCR 与剪贴板

- OCR 依赖系统 tesseract 和语言包，识别效果取决于画面清晰度与语言配置。
- 推荐安装 wl-clipboard；复制 GIF 文件需要 wl-copy。图片与文字复制有 Qt 剪贴板回退路径。
- Wayland 下，贴图会被自排除出之后的截图；肉眼可见的贴图不会再次进入截图结果。

## 📜 长截图与贴图的边界

- 长截图**不注入滚动事件**：需要你自己滚（滚轮 / 触控板 / 拖滚动条 / PageDown 都行），
  **结束也由你决定**（点指示器「完成」或按 `Esc`）；兜底只有高度 20 000 px 与时长 30 分钟。
  这样设计是因为：自动判定“用户滚完了”在真实页面上不可靠（固定页头、动画、加载中都可能误判）。
- 拼接对齐依赖**重叠区逐像素匹配**，以下情况会影响结果：滚动中的平滑动画（分数像素位移，会被残差拒帧，
  实测 22 帧里拒 6 帧仍能拼对）、页面一直在动（视频/轮播）、固定页头/底栏与边缘滚动条
  （代码会尝试自动裁掉，但并非万能）。
- 贴图在 Wayland 下会被**自排除**出之后的截图：肉眼看得到、新截图里拍不到。

## ⌨️ 全局快捷键的边界

- 快捷键**需要应用常驻**才能响应（门户与 KGlobalAccel 都只是把按键事件交给注册它的进程）；
  推荐 `./install.sh --autostart`。
- 门户（`GlobalShortcuts`）授权**只在“首次 / 新快捷键 id”时弹窗**：KDE 6 里 KGlobalAccel 与门户
  共用同一份快捷键存储，已被 KGlobalAccel 建过条目的 id 会被视为“已知”而静默放行。
- 门户**没有“忘记授权”的 API**：要重新走一次授权，需停止 `plasma-kglobalaccel.service`，
  从 `~/.config/kglobalshortcutsrc` 的 `[seashot]` 段删掉对应 id，再发起。
- 门户已授权时程序不再注册 KGlobalAccel（避免系统设置里出现两条同键快捷键）；
  系统设置里那条空键的 `SeaShot 截图` 是 KGlobalAccel 的组件条目，空键不参与任何按键。

## 🍞 交付方式与已失效配置

- 截图完成后**不弹结果窗口**，只按设置复制/保存；另存与编辑走托盘「保存 / 导出上一次结果…」。
- `ui/toastAutoHideMs` 已失效：结果浮层（Toast）在产品路径退役，仅 `--toast-drag-bench` 诊断在用。

## 🧪 验证方式

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j 2
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure
```

自动化测试覆盖截图生命周期、迟到响应、冻结图一致性、键盘映射、实例转发、录制参数与编码时间轴，也验证打开 KDE 快捷键设置时不会把 SeaShot 的 layer-shell 环境传给子进程。模拟后端和 offscreen 测试不代替真实桌面验证。
